# KfuPet 网站功能说明

> KfuPet Website / KfuPet Hub  
> 用于承载 KfuPet 的社区交流、模型包分发以及账号与开发者生态。

---

## 1. 网站定位

KfuPet 网站不是单纯的项目官网，而是 KfuPet 的配套平台。

网站主要承担两个相互独立、但可以互相联动的核心业务：

1. **社区交流平台**
   - 用户发布帖子、讨论问题、分享经验。
   - 围绕 KfuPet、角色制作、模型制作、开发等主题进行交流。
2. **模型包平台**
   - 提供 KfuPet 角色包 / 模型包的上传、发布、下载、版本管理和展示。
   - 为 KfuPet Windows / Android 客户端提供在线模型资源接口。

网站后续可以继续扩展账号体系、开发者中心、反馈系统、管理后台等功能。

# 3. 首页

首页用于展示 KfuPet 项目及网站的核心内容。

首页可以包含：

- KfuPet 项目简介

- 热门社区帖子
- 最新模型包
- 热门模型包
- 最近更新的模型包
- 网站公告
- KfuPet 客户端下载入口
- GitHub 项目入口

首页的主要目标是让用户快速进入：

- 模型包平台

# 4. 社区交流平台

社区是网站的第一大板块。

社区主要用于用户交流、问题讨论、项目分享以及经验交流。

---

## 4.1 帖子系统

用户可以创建帖子。

帖子至少包含：

- 标题
- 正文
- 作者
- 发布时间
- 修改时间
- 分类
- 标签
- 浏览量
- 点赞数量
- 评论数量

帖子内容建议支持 Markdown。

---

## 4.2 社区分类

社区可以根据内容划分不同分类。

例如：

```text
综合讨论
KfuPet 使用
问题反馈
角色制作
模型制作
开发交流
插件 / 工具
公告
```

分类可以随着社区规模增长继续扩展。

---

## 4.3 标签系统

帖子可以添加多个标签。

例如：

```text
#KfuPet
#WinUI
#WPF
#模型包
#角色制作
#开发
#Bug
#教程
```

用户可以通过标签查看相关帖子。

---

## 4.4 评论系统

帖子支持评论。

基础功能：

- 发布评论
- 删除自己的评论
- 回复评论
- 评论点赞

后续可以扩展：

- 评论举报
- 评论审核
- 评论置顶

---

## 4.5 帖子互动

用户可以对帖子进行：

- 点赞
- 收藏
- 分享

网站可以统计：

- 浏览量
- 点赞量
- 收藏量
- 评论量

用于生成热门内容。

---

# 5. 模型包平台

模型包平台是网站的第二大板块。

该模块是 KfuPet 网站区别于普通社区网站的重要功能。

主要目标是：

> 为 KfuPet 提供统一的角色包 / 模型包分发平台。

---

## 5.1 模型包列表

用户可以浏览所有公开模型包。

模型包列表可以显示：

- 模型包名称
- 缩略图
- 作者
- 当前版本
- 更新时间
- 下载量
- 收藏量
- 标签
- 简介

支持：

- 最新排序
- 热门排序
- 下载量排序
- 更新时间排序

---

## 5.2 模型包搜索

用户可以搜索模型包。

搜索内容可以包括：

- 模型包名称
- 作者
- 标签
- 分类
- 关键词

例如：

```text
搜索：猫娘
```

返回所有相关模型包。

---

## 5.3 模型包分类

模型包可以拥有分类。

例如：

```text
角色
宠物
桌宠
场景
测试
其他
```

具体分类可以随着模型库发展调整。

---

# 6. 模型包详情页

每个模型包都有独立的详情页面。

详情页至少包含：

- 模型包名称
- 封面
- 预览图
- 作者
- 简介
- 标签
- 当前版本
- 文件大小
- 下载次数
- 发布时间
- 最后更新时间

同时展示模型包的详细说明。

---

## 6.1 模型包版本

模型包需要支持版本管理。

例如：

```text
1.0.0
1.1.0
1.2.0
2.0.0
```

每个版本可以拥有：

- 版本号
- 发布时间
- 文件
- 文件大小
- 更新日志
- 最低 KfuPet 版本要求

例如：

```text
版本：1.2.0

更新内容：
- 添加新动画
- 修复模型显示问题
- 优化资源大小

最低 KfuPet 版本：
0.2.0
```

这样可以避免模型包升级后导致旧版客户端无法正常使用。

---

# 7. 模型包上传

登录用户可以上传自己的模型包。

上传流程：

```text
选择模型包
    ↓
填写名称
    ↓
填写介绍
    ↓
选择分类
    ↓
填写标签
    ↓
上传封面 / 预览图
    ↓
填写版本
    ↓
提交
    ↓
审核
    ↓
公开发布
```

---

## 7.1 模型包文件

模型包建议使用 KfuPet 自己定义的模型包格式。

例如：

```text
character.kfupet
```

本质上可以是经过约定结构组织的压缩包。

模型包内部可以包含：

```text
model/
animation/
images/
audio/
config.json
manifest.json
```

具体文件结构由 KfuPet 客户端定义。

# 8. 模型包审核

为了避免恶意文件、错误资源或违规内容进入模型库，模型包建议支持审核状态。

例如：

```text
草稿
待审核
审核中
已发布
已拒绝
已下架
```

管理员可以：

- 审核模型包
- 拒绝模型包
- 下架模型包
- 恢复模型包
- 查看审核记录

---

# 9. 模型包下载

用户可以直接从网站下载模型包。

基础流程：

```text
模型包详情页
    ↓
点击下载
    ↓
获取文件
```

网站记录：

- 下载用户
- 下载时间
- 模型包
- 模型包版本

用于统计模型包下载量。

# 10. KfuPet 客户端联动

模型包平台不仅服务于网页用户，还要为 KfuPet 客户端提供 API。

例如：

```text
KfuPet
   ↓
请求模型列表 API
   ↓
服务器返回模型信息
   ↓
用户选择模型
   ↓
客户端下载模型包
   ↓
导入本地模型库
```

客户端可以使用 API 获取：

- 模型包列表
- 模型包详情
- 最新版本
- 更新日志
- 下载地址
- 模型包缩略图

---

## 10.1 客户端在线模型库

未来 KfuPet 可以直接提供：

```text
角色管理
    ↓
在线模型库
    ↓
浏览模型
    ↓
查看详情
    ↓
下载
    ↓
```



```text
社区帖子
```

# 18. 文件存储

网站中的大文件不建议直接存储在 PostgreSQL 中。

数据库只保存文件信息。

例如：

```text
PostgreSQL
    ↓
模型包名称
版本
文件大小
Storage Key
下载统计
```

真正的模型包文件存储在：

```text
S3 / Cloudflare R2 / 其他对象存储
```

目录可以类似：

```text
packages/
    {package-id}/
        {version}/
            package.kfupet

images/
    packages/
        {package-id}/
            cover.webp
            preview-01.webp
            preview-02.webp
```

这样可以减少网站服务器的存储压力。
