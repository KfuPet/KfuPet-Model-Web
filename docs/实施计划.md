# KfuPet 网站实施计划

> 配套 [KfuPet_Website_Function_Specification.md](./KfuPet_Website_Function_Specification.md) 与 [架构.md](./架构.md)。
> 本计划聚焦「第一阶段 MVP」，并给出后续阶段的任务清单。

---

## 1. 目标与范围

第一阶段（MVP）目标：把「社区 + 模型包」两个核心板块跑通，形成最小可用闭环。

MVP 范围：

- 首页（项目简介、最新/热门帖子、最新模型包）
- 社区：帖子（发帖/列表/详情/编辑/删除）、评论（发布/删除/回复）、分类、标签
- 模型包：列表 / 详情 / 上传 / 下载 / 版本管理
- 账号：注册 / 登录 / 个人中心
- 基础管理后台（用户管理、帖子管理、模型包审核）
- 文件存储：**本地磁盘**（后续切换 S3/R2）

暂不实现（后续阶段）：搜索、收藏、点赞、举报、通知、作者主页、下载统计、客户端在线模型库。

## 2. 技术选型

| 部分 | 选型 | 说明 |
| --- | --- | --- |
| 前端框架 | Vue 3 + TypeScript + Vite | 按架构文档 |
| UI 组件库 | Naive UI | 风格现代，TypeScript 支持好 |
| CSS 框架 | Tailwind CSS | 快速布局与样式 |
| 后端框架 | NestJS + TypeScript | 按架构文档 |
| ORM | Prisma | 类型安全、迁移方便，适合快速开发 |
| 数据库 | PostgreSQL | 按架构文档 |
| 认证 | JWT + Passport + bcrypt | 无状态，便于后续客户端接入 |
| 校验 | class-validator + class-transformer | NestJS 标准 |
| 文件上传 | Multer（本地磁盘） | 第一阶段 |
| 包管理 | pnpm（前端）/ npm 或 pnpm（后端） | 保持简单，前后端各自独立 |

> 备选：ORM 也可用 TypeORM（更贴近 NestJS 装饰器风格）。UI 已确定为 Naive UI + Tailwind CSS。默认按上表执行。

## 4. 数据模型（Prisma schema）

### 用户与账号

- **User**：id、username（唯一）、email（唯一）、passwordHash、avatarUrl、bio、role（USER/ADMIN/SUPERADMIN）、status（ACTIVE/DISABLED）、createdAt、updatedAt

### 社区

- **CommunityCategory**：id、name、slug（唯一）、description、sortOrder
- **Tag**：id、name、slug（唯一）
- **Post**：id、title、content（Markdown）、authorId、categoryId、viewCount、likeCount、commentCount、isPinned、isFeatured、status（PUBLISHED/HIDDEN/DELETED）、createdAt、updatedAt；与 Tag 多对多
- **Comment**：id、postId、authorId、parentId（可空，用于回复）、content、likeCount、status、createdAt

### 模型包

- **ModelCategory**：id、name、slug（唯一）、description
- **ModelPackage**：id、name、slug（唯一）、description、coverUrl、previewUrls（JSON 数组）、authorId、categoryId、status（DRAFT/PENDING/REVIEWING/PUBLISHED/REJECTED/OFFLINE）、downloadCount、favoriteCount、createdAt、updatedAt；与 Tag 多对多
- **PackageVersion**：id、packageId、version、changelog、fileSize、storageKey、minKfuPetVersion、downloadCount、createdAt
- **DownloadRecord**：id、userId、packageId、versionId、createdAt

### 通用

- **Favorite**：id、userId、targetType（POST/PACKAGE）、targetId、createdAt（第二阶段用，可先预留）
- **Report**：id、reporterId、targetType、targetId、reason、status（PENDING/PROCESSING/RESOLVED/REJECTED）（第二阶段）

> 第一阶段先落地 User / CommunityCategory / Tag / Post / Comment / ModelCategory / ModelPackage / PackageVersion / DownloadRecord。Favorite、Report、Notification 在第二阶段实现。

## 5. API 设计（REST，统一 `/api` 前缀）

### 认证

```http
POST /api/auth/register         # 注册
POST /api/auth/login            # 登录，返回 JWT
GET  /api/users/me              # 当前用户信息
PATCH /api/users/me             # 更新个人资料
```

### 社区

```http
GET    /api/community/categories        # 分类列表
GET    /api/community/posts             # 帖子列表（分页/分类/标签/排序）
GET    /api/community/posts/:id         # 帖子详情（浏览量 +1）
POST   /api/community/posts             # 发帖（需登录）
PATCH  /api/community/posts/:id         # 编辑（作者/管理员）
DELETE /api/community/posts/:id         # 删除（作者/管理员）

GET    /api/community/posts/:id/comments # 评论列表（含回复）
POST   /api/community/posts/:id/comments # 发表评论/回复（需登录）
DELETE /api/community/comments/:id       # 删除自己的评论

GET    /api/tags                          # 标签列表/搜索
```

### 模型包

```http
GET    /api/models                         # 模型包列表（分页/分类/标签/排序）
GET    /api/models/:id                     # 模型包详情
POST   /api/models                         # 创建模型包（需登录）
PATCH  /api/models/:id                     # 更新（作者/管理员）
DELETE /api/models/:id                     # 删除（作者/管理员）

GET    /api/models/:id/versions            # 版本列表
POST   /api/models/:id/versions            # 上传新版本（需登录）
GET    /api/models/:id/versions/:versionId/download # 下载（记录下载量）

GET    /api/model-categories               # 模型包分类列表
```

### 管理后台（需管理员）

```http
GET    /api/admin/users                    # 用户列表
PATCH  /api/admin/users/:id/status         # 禁用/解禁
GET    /api/admin/models/pending           # 待审核模型包
PATCH  /api/admin/models/:id/review        # 审核（通过/拒绝/下架）
```

## 6. 分阶段任务清单

### 第一阶段（MVP）

1. 项目骨架：初始化 `frontend/`（Vite + Vue3 + TS + Element Plus）与 `backend/`（NestJS + Prisma），配置 `.env` 与 PostgreSQL 连接
2. 数据库：编写 Prisma schema、执行迁移、写入分类/种子数据
3. 认证：注册/登录/JWT 守卫 + bcrypt 密码哈希
4. 社区：帖子 CRUD、评论（含回复）、分类、标签
5. 模型包：列表/详情/创建/编辑、版本、下载，文件本地磁盘存储（Multer）
6. 首页：聚合最新/热门帖子、最新模型包
7. 个人中心：资料编辑、我的帖子、我的模型包
8. 基础管理后台：用户管理、帖子管理、模型包审核
9. 联调与验证：前后端跑通核心闭环（注册 → 发帖 → 评论；注册 → 上传 → 下载）

### 第二阶段

搜索、收藏、点赞、举报、模型包审核流程完善、通知、作者主页、下载统计。

### 第三阶段

KfuPet 客户端在线模型库、自动下载/更新、客户端账号登录、开发者 API / 开放平台。
